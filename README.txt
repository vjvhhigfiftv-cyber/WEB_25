بلاك ويب - نسخة مصححة للنشر

1) أضف متغير البيئة BOT_TOKEN في منصة الاستضافة وضع توكن البوت الجديد.
2) أضف ADMIN_ID إذا أردت تغييره. القيمة الافتراضية داخل الكود هي 6040546032.
3) أمر التشغيل:
   python bot.py

تم تصحيح:
- Procfile ليكون بصيغة صحيحة.
- إضافة Dockerfile للنشر عبر Docker/Nixpacks والمنصات التي تدعم Docker.
- تثبيت نسخة محددة ومتوافقة من pyTelegramBotAPI.
- إزالة حقول InlineKeyboardButton غير المدعومة في Telegram Bot API.
- إصلاح فحص عضوية دردشة بلاك ليستخدم @blacke13 بدل رابط t.me.
- تحسين تنظيف حالات المستخدم.
- منع استهلاك الكوبون قبل نجاح عملية الشراء.
- عدم وضع توكن البوت داخل الملف البرمجي.

مهم جداً:
التوكن القديم كان موجوداً داخل الملف المرفوع، لذلك اعتبره مكشوفاً وأصدر توكناً جديداً من BotFather ثم ضعه في BOT_TOKEN.
